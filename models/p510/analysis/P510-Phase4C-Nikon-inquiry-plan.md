## Purpose and evidence boundary

Request historical preservation and version-verification information for a personally owned Nikon COOLPIX P510. The request does not claim that Nikon never released body firmware, and it does not seek source code, encryption keys, credentials, or confidential service-system access.

Phase 4B found no public camera-body firmware updater on the current official P510 Download Center page. Sixteen archived captures from 2015-06-14 through 2023-04-07 list only an A-GPS Update File. Nikon's archived description identifies `NML_28A.ee` as A-GPS assistance data, not camera-body firmware. No updater filename or body-firmware package was recovered. There is no P510 page capture before 2015-06-14, and some regional archive research was incomplete. The conclusion remains **PARTIALLY SUPPORTED**, not proof that no body firmware existed.

The camera's displayed firmware is Version 1.0. That observation does not establish whether it was the only production version or whether a later, internal, service, or recovery version existed. P500/P520 packages are not relevant to the request and are not represented as P510-compatible.
