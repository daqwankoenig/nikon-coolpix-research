# Model intake checklist

1. Registry row complete (exact Nikon name, regional variants, family, official source links).
2. Model folder created from `templates/model/`.
3. Every capability starts UNKNOWN; every step starts Not started.
4. Official sources recorded as links, with date checked and the firmware/region each covers. No Nikon files copied.
5. `known-facts.md` starts empty. Nothing carried over from another model.
6. A named owner and a reason (why this camera, who asked).
7. One-line status in `README.md`.
